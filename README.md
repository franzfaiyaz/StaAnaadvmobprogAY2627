# Lab Activity 5: Firebase Authentication and UserService

Name: Justine Francis Sta. Ana

## Discussion

This lab activity focused on integrating Firebase Authentication with the existing DummyJSON login system in a Flutter application, allowing users to register, sign in, and manage their accounts through two separate authentication methods. It involved enhancing the UserService to handle authentication, user data, token refreshing, persistent sessions, logout, username updates, password changes, and account deletion while using Firebase to securely manage user credentials and account information. The application was also improved with a validated sign-up screen, an updated sign-in process, and a profile screen that displays information based on the selected authentication method. Additionally, the splash screen checks the user's saved session to determine whether to navigate to the home screen or sign-in page, making the application more secure, organized, user-friendly, and easier to maintain.
