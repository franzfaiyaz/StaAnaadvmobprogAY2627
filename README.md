## Lab Activity 4: Discussion

This lab activity focused on implementing persistent authentication, user profile management, and cart functionality using Provider, API integration, and SharedPreferences. It involved creating a User model to manage account information, connecting the UserService to the login API, and securely saving user data locally so the application can remember the authenticated user even after being closed and reopened. It also enhanced the splash screen and sign-in screen with custom designs, loading indicators, form validation, and automatic navigation based on the user's login status. Additionally, the profile screen was improved to display actual user information, support logout, and retrieve the correct shopping cart using the saved user ID, while maintaining a structured separation between models, services, screens, and providers for better code organization, readability, and maintainability.
